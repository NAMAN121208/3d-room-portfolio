# 3D Room Portfolio

A personal portfolio website shaped like an interactive **3D isometric room**. Drag to rotate, wheel or pinch to zoom, and click one of six objects to focus its view and open its panel.

## Tech Stack
- **Build**: Vite + React
- **Styling**: Tailwind CSS
- **3D**: Three.js via `@react-three/fiber` (R3F) + `@react-three/drei`
- **Controls & Animation**: drei OrbitControls, GSAP camera tweens, Framer Motion
- **Backend / Integrations**: Serverless functions in `/api` (GitHub GraphQL & Spotify)

Refer to [AGENTS.md](./AGENTS.md) for the project contract, architecture, and team workflows.
