# 3D Room Portfolio

A personal portfolio website shaped like an interactive **3D isometric room**. As the visitor scrolls, the camera glides from object to object across 8 stops, with click-to-zoom interactive panels.

## Tech Stack
- **Build**: Vite + React
- **Styling**: Tailwind CSS
- **3D**: Three.js via `@react-three/fiber` (R3F) + `@react-three/drei`
- **Scroll & Animation**: GSAP + ScrollTrigger, Lenis, Framer Motion
- **Backend / Integrations**: Serverless functions in `/api` (GitHub GraphQL & Spotify)
